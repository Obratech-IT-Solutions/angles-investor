4. Admin dashboard overview (KPIs and charts)
5. Managing financiers (create, edit, activate/deactivate, unlock, reset password)
6. Creating and editing projects
7. Inviting financiers and reading suggested amounts
8. Reviewing willing amounts and funding gap
9. Confirming allocations (rules, overfunding prevention)
10. Project statuses explained
11. Setting and changing release dates
12. Recording releases and viewing payments
13. Overdue projects
14. Audit log
15. Personal admin profile and password change
16. Troubleshooting and contacting support (ObraTech)
